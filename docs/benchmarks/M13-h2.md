# M13: HTTP/2 flow control and limits (h2load)

- Date: 2026-11-11, commit e94c98b plus the #0056 working tree (`sws-bench serve --h2`)
- Machine: Apple M4 Pro, 12 cores, 64 GB, macOS 27.0, Swift 6.4.2, release build
- Load average: before the sws-bench runs 3.29 4.31 12.91, after 3.29 4.31 12.91; before the
  256 KiB runs 2.91 4.12 12.55, after 4.36 4.40 12.60; before the nginx runs 3.20 4.12 12.26,
  after 3.78 4.21 12.10. No other agent was building during the runs.
- Client: h2load nghttp2/1.71.0, cleartext HTTP/2 with prior knowledge, default windows
  (64 KiB − 1 per stream, 1 GiB connection), loopback.
- Server: `.build/release/sws-bench serve --h2 --port 0` (HTTP/2 registered before HTTP/1.1,
  the built-in handler answering from memory: `Hello, World!\n`, or `--body-size 262144` bytes
  of `x`). Every #0053–#0056 limit at its default.
- nginx/1.31.8 for scale: `worker_processes auto`, `listen 127.0.0.1:PORT; http2 on;`
  (h2c prior knowledge), `access_log off`, `keepalive_requests 1000000`,
  `http2_max_concurrent_streams 100`; `/` is `return 200 "Hello, World!\n"`, `/big` a
  256 KiB file (page cache). The config lived in the session scratchpad.
- Each case ran three times; the table shows the median run.

## Notes

- This is the first HTTP/2 load record, so there is no previous record to compare with.
- The nginx spread between runs is over 10% in the small-body case, so its numbers are for
  scale only. sws-bench answers from memory; nginx's `/big` reads a file from the page cache
  (HTTP/2 does not use sendfile in nginx).
- No run tripped an abuse limit (#0056): h2load opens 16 connections and sends 12,500 requests
  on each, below `maxStreamsPerConnection` (100,000), and returns credit at half a window, so no
  DATA frame falls below `smallDataFrameSize`.
- `HTTP2Tests.H2CurlTests` runs h2load as a smoke test (`h2loadRequestsAllSucceed`,
  `h2loadSmallWindowsDownloadWhole` with 16 KiB stream and 64 KiB connection windows) through
  `HTTPTestSupport.ChildProcess`, when `/opt/homebrew/bin/h2load` is installed.
