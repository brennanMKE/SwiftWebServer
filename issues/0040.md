# 0040 — Implement the HPACK header block decoder

| | |
|---|---|
| **Status** | open |
| **Module** | HPACK |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

Decode complete header blocks into ordered header field lists (RFC 7541 §6).

## Scope

- Indexed field, literal with incremental indexing, literal without indexing, and literal never indexed (the never-indexed flag is surfaced to callers).
- Dynamic table size updates are allowed only at the start of a block and must not exceed the `SETTINGS_HEADER_TABLE_SIZE` the server advertised.
- The maximum header list size is enforced incrementally while decoding, which defeats HPACK bombs.
- Any error is a connection-level `COMPRESSION_ERROR`, and the decoder state is unusable afterward.

## Acceptance criteria

- RFC 7541 Appendix C.3, C.4, C.5, and C.6 request and response sequences decode, including the dynamic table contents after each step.
