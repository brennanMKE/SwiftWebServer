# 0110 — permessage-deflate compresses WebSocket messages (optional)

| | |
|---|---|
| **Status** | open |
| **Module** | WebSockets / Compression |
| **Platform** | macOS |
| **First seen** | 2026-11-11 |

## Description

Optional: RFC 7692 permessage-deflate reduces bandwidth for text-heavy WebSocket traffic.

## Scope

- Extension negotiation with `server_no_context_takeover`, `client_no_context_takeover` and `*_max_window_bits` parameters; RSV1 accepted only when negotiated.
- Raw deflate via Apple's Compression framework (shared primitive from #0091); trailing `00 00 ff ff` handling; context takeover per negotiated parameters.
- Decompression bomb protection: decompressed message size bounded by the max message size.

## Acceptance criteria

- `URLSessionWebSocketTask` (which offers permessage-deflate) echoes compressed text messages correctly; a compressed message that inflates beyond the limit closes with 1009.
- RFC 7692 §7.2.3 examples decode.
