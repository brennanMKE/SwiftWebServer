# 0111 — WebSockets run over HTTP/3 with extended CONNECT per RFC 9220

| | |
|---|---|
| **Status** | open |
| **Module** | WebSockets / HTTP3 |
| **Platform** | macOS |
| **First seen** | 2026-11-11 |

## Description

RFC 9220 bootstraps WebSockets over an HTTP/3 request stream using extended CONNECT. Reuse the `.tunnel` hook and #0109 unchanged. RFC 8441 over HTTP/2 stays in #0067.

## Scope

- Advertise `SETTINGS_ENABLE_CONNECT_PROTOCOL = 1` when the WebSockets component is registered (#0100).
- Accept `:method CONNECT` with `:protocol websocket`, `:scheme`, `:path`, `:authority`; respond `200` and keep the stream open; the stream becomes the `ByteStreamTransport` handed to `.tunnel`.
- Stream FIN and reset map to WebSocket close and abort.

## Acceptance criteria

- In-memory test over `InMemoryMultiplexedTransport`: extended CONNECT then a text echo and close handshake.
- If a client on this machine supports RFC 9220 (checked and recorded), an end-to-end echo; otherwise the resolution states that and relies on the in-memory test.
