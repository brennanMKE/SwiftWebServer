## Description

Implement the static Huffman code from RFC 7541 Appendix B.

## Scope

- Encoder using the 257-symbol code table.
- Table-driven decoder (for example, a 4-bit or 8-bit state machine) that rejects padding longer than 7 bits, padding that is not the most significant bits of EOS, and an EOS symbol appearing in the data (§5.2).
- Encoded-length calculation, so the encoder can choose Huffman only when it is shorter.

## Acceptance criteria

- Huffman strings from RFC 7541 Appendix C.4 and C.6 decode and encode byte-for-byte.
- Padding error cases throw `COMPRESSION_ERROR`.
