# 0066 — Support server push behind a config flag

## Description

Implement PUSH_PROMISE (RFC 9113 §8.4) for completeness. Chrome and Firefox no longer accept pushes, so the feature is off by default.

## Scope

- Push only when the client's `SETTINGS_ENABLE_PUSH` is 1 and `http2.push.enabled` is true.
- Server-initiated even stream ids, the reserved (local) state, promised request headers that must be cacheable and safe, and a response dispatched through the handler.
- Configuration maps a path to the assets to push (for example, `index.html` pushes `swift.png`).
- An RST_STREAM(CANCEL) from the client for a promised stream is handled cleanly.

## Acceptance criteria

- A test client with push enabled receives the promised response. With push disabled, nothing is sent.

Owner decision 2026-11-11. Server push is deprecated; major browsers no longer accept PUSH_PROMISE. See docs/ROADMAP.md §2.
