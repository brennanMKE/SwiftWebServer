# 0004 — Startup failures are swallowed and the process hangs

| | |
|---|---|
| **Status** | open |
| **Module** | Lifecycle |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

If bootstrap throws (for example, `http-config.json` is missing or fails to decode), nothing is logged to the console and the process hangs forever instead of exiting. Verified on 2026-09-12 with `ROOT_PATH=/nonexistent`.

## Steps to reproduce

1. `ROOT_PATH=/nonexistent .build/debug/SwiftWebServer`
2. Wait.

## Expected behavior

The error is logged and the process exits with `EXIT_FAILURE`.

## Actual behavior

The process stays alive in `dispatchMain()` and serves nothing.

## Notes

In `Sources/SwiftWebServer/main.swift:9-21` the `do/catch` wraps the creation of a `Task`, not the throwing work inside it. The compiler already warns: "'catch' block is unreachable because no errors are thrown in 'do' block". Errors thrown inside the `Task` are discarded. Move the `do/catch` inside the task, or use an `@main` async entry point. The result of `bootstrap()` is also unused (another warning).
