## Description

Support HTTP/2 with prior knowledge over cleartext (h2c, RFC 9113 §3.3). Peek the first 24 octets of each cleartext connection. If they match `PRI * HTTP/2.0\r\n\r\nSM\r\n\r\n`, run the HTTP/2 connection. Otherwise replay the bytes into the HTTP/1.1 codec. This is the first HTTP/2 milestone because it needs no certificates.

## Scope

- Implement `HTTP2.matchesCleartextPreface(_:)` for the `ConnectionProtocol` registry (#0088): `.needMoreBytes` until 24 octets or a mismatch, then `.match` or `.noMatch`. The registry hands the sniffed bytes to the chosen protocol without copying, so no peeking wrapper is needed.
- The first frame after the preface must be SETTINGS, or the result is a `PROTOCOL_ERROR` connection error.
- Enable with `http2.cleartext` in config (defaults per the limits table in `docs/HTTP2.md`, decoded as optional keys by `ConfigFile`, #0086).

## Acceptance criteria

- An in-memory transport test verifies routing for the preface, for an HTTP/1.1 request, and for a connection that sends fewer than 24 bytes and then closes.

## Root cause

Feature work: no `ConnectionProtocol` spoke HTTP/2, and the registry's sniff let a later protocol that already matched win over an earlier one that was still undecided. HTTP/1.1's method sniff matches `PRI ` after four bytes, so with `[HTTP2(), HTTP1()]` a preface that arrived in pieces would have been routed to HTTP/1.1.

## Fix

- `HTTP2` (`Sources/HTTP2/HTTP2.swift`) conforms to `ConnectionProtocol`: `alpnTokens == ["h2"]`, and `matchesCleartextPreface` delegates to `HTTP2Preface.match`, which answers `.needMoreBytes` for a proper prefix of `PRI * HTTP/2.0\r\n\r\nSM\r\n\r\n`, `.noMatch` at the first octet that differs, and `.match` at 24 octets.
- `ProtocolRegistry.select`: protocols are asked in registration order and the first one that has not ruled the bytes out decides (`.match` selects it, `.needMoreBytes` reads more). Existing registry tests are unchanged and pass. Registering `[HTTP2(), HTTP1()]` routes `h2` over TLS by ALPN, the preface over cleartext, and everything else to HTTP/1.1; the TLS listener offers `h2, http/1.1`.
- `HTTP2Configuration` holds the docs/HTTP2.md limits as the advertised SETTINGS and `cleartext` (config key `http2.cleartext`, default true). With `cleartext: false` a cleartext connection that reaches HTTP/2 is closed; TLS `h2` is always served.
- `run` sends the server SETTINGS first, checks the preface, and requires SETTINGS as the first frame (`GOAWAY(PROTOCOL_ERROR)` otherwise). This first step then closes with `GOAWAY(NO_ERROR)`; #0043 and #0044 replace it with the real connection.
- `Package.swift`: `HTTP2Tests` also depends on `HTTPTestSupport`, `HTTPServer`, `HTTP1` and `NetworkTransport` (one line).

## Verification

- `scripts/guarded.sh -t 900 -- swift test -j 2 --filter "HTTP2Tests|HTTPServerTests"`: 89 tests passed, including the new `H2PrefaceTests` (10 tests):
  - `sniffMatchesOnlyTheWholePreface`: every proper prefix, a flipped byte at each of the 24 positions, HTTP/1.1 request lines;
  - `registryWaitsForTheWholePreface`: `[HTTP2(), HTTP1()]` stays undecided for every prefix, then selects HTTP/2; `GET` and `PRI /` go to HTTP/1.1; ALPN `h2` and the TLS default;
  - in-memory routing through `ProtocolRegistry.serve`: the preface (also split at every byte position and byte by byte) reaches HTTP/2, whose first frame is SETTINGS; an HTTP/1.1 request (three chunkings) gets `200`; 0 to 23 preface bytes followed by end of stream close with nothing sent; a wrong preface on a TLS `h2` connection and a first frame other than SETTINGS get `GOAWAY(PROTOCOL_ERROR)`; `cleartext: false`.

## Gotchas

- Register `HTTP2` before `HTTP1`. In the other order HTTP/1.1 is asked first and matches `PRI `.
- The `SwiftWebServer` executable (`ServerMain`, #0086) still registers only `HTTP1`, and `ConfigFile` has no `http2` keys yet. Registering a second protocol puts every cleartext connection through the sniff and `PrefixedTransport`, which takes a lock on every receive. That cost should be measured before the CLI turns HTTP/2 on by default.
