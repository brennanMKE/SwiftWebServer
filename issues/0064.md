## Description

Make HTTP/2 behavior debuggable without a packet capture.

## Scope

- `os.Logger` categories: `connection`, `http1`, `http2.frames` (debug-level frame trace), `hpack`, and `flow-control`.
- Signposts for connection lifetime, stream lifetime, and handler duration, so Instruments can show multiplexing.
- An access log line per request: protocol, method, path, status, bytes, and duration.
- Counters for active connections and streams, resets, and GOAWAYs, logged at shutdown.

## Acceptance criteria

- `log stream --predicate 'subsystem == "HTTPServer"'` shows a readable trace for one multiplexed curl session.
