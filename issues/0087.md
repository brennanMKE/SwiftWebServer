# 0087 — TLS identities load from configuration and a TLS listener serves HTTP/1.1

| | |
|---|---|
| **Status** | open |
| **Module** | NetworkTransport / ConfigFile |
| **Platform** | macOS |
| **First seen** | 2026-11-11 |

## Description

There is no TLS (#0057). Load a server identity and add a TLS listener using `NWProtocolTLS`, configured inside `NetworkTransport`.

## Scope

- Identity loading from a PKCS#12 file with password (from config or environment) via `SecPKCS12Import`, or from the keychain by label; clear errors for a wrong password or missing file.
- `NWProtocolTLS.Options` with minimum TLS 1.2, `sec_protocol_options_set_local_identity`; TLS flag exposed on `ConnectionInfo`.
- Config keys for the TLS listener port, identity path and password source, all optional with defaults (TLS disabled when absent).
- Uses the identity from #0072 in tests.

## Acceptance criteria

- `curl -k https://localhost:8443/` and `curl --cacert TestIdentity/ca.pem https://localhost:8443/` return the index page.
- A `URLSession` test with a trust override for the test CA fetches a file over TLS.
- A wrong PKCS#12 password exits 1 with a message naming the identity file.
