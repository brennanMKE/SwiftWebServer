## Description

Run [h2spec](https://github.com/summerwind/h2spec) against the server and fix every failure.

## Scope

- A `scripts/run-h2spec.sh` script that starts the server, runs `h2spec -h localhost -p <port>` (cleartext) and `h2spec -t -k -p <tls port>`, and stops the server. Document `brew install h2spec`.
- Triage failures into separate issues when they are non-trivial.
- Record the final pass count in `docs/HTTP2.md`.

## Acceptance criteria

- h2spec reports 0 failures for the `http2` and `hpack` sections.
