# 0002 — HTTPServer is a singleton with a private initializer, which blocks configuration injection and testing

| | |
|---|---|
| **Status** | open |
| **Module** | Lifecycle / Config |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

`HTTPServer.default` is the only way to get a server (`HTTPServer.swift:17-22`). Configuration is found implicitly through the `ROOT_PATH` environment variable or the current directory (`HTTPServer.swift:25`), and `HTTPRuntime.bootstrap` can only run once per process (`HTTPRuntime.swift:74`). Tests cannot start a server on an ephemeral port with a temporary document root, or run more than one server.

## Expected behavior

A server can be constructed with an explicit `HTTPConfig` (or root URL) and port, including port `0` for an OS-assigned port, and the bound port is readable after startup. Several servers can run in one test process.

## Actual behavior

Only the process-wide singleton exists, bound to the port in `http-config.json`.

## Notes

- Keep a convenience entry point in `main.swift` that reads `ROOT_PATH`.
- Commit `093c120` ("refactors HTTPServer initialization to separate config") started this separation.
