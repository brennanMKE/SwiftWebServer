# 0039 — Implement HPACK static and dynamic tables

## Description

Implement the indexing tables from RFC 7541 §2.3 and §4.

## Scope

- The 61-entry static table (Appendix A) with fast name and name-value lookup for the encoder.
- A dynamic table as a ring buffer, entry size = name + value + 32, FIFO eviction, and a table that can shrink to 0 (§4.4).
- A unified index address space (static 1–61, dynamic 62 and up). Out-of-range indexes throw.

## Acceptance criteria

- Tests for eviction order, a size update that evicts everything, an entry larger than the table (which empties it), and index lookup.
