# 0093 — Auth component protects paths with Basic or bearer-token authentication

| | |
|---|---|
| **Status** | open |
| **Module** | Auth |
| **Platform** | macOS |
| **First seen** | 2026-11-11 |

## Description

Provide opt-in authentication for selected path prefixes.

## Scope

- Basic auth against a configured credential file (hashed passwords, constant-time compare) and static bearer tokens.
- `401` with `WWW-Authenticate` on missing or bad credentials; principal stored in `RequestContext`.
- Never logs credentials; `authorization` marked sensitive so HPACK/QPACK use never-indexed literals.

## Acceptance criteria

- Tests for valid, invalid and missing credentials and constant-time comparison helper.
- `curl -u user:pass` succeeds and `curl` without credentials gets 401 on a protected path.
- `sws-bench` shows no change (< 2%) with the component unregistered.
