## Description

Measure throughput and latency and remove obvious inefficiencies.

## Scope

- A `bench.sh` script using `h2load` (`brew install nghttp2`) for h2c, h2 over TLS, and HTTP/1.1 (`--h1`), at a few concurrency levels, for a small and a large file.
- Profile with Instruments (Time Profiler, Allocations) and address the top costs, such as byte copying between `Data` and `[UInt8]`, per-frame allocations, and actor hops per DATA frame.
- Record before and after numbers in `HTTP2.md`.

## Acceptance criteria

- Benchmarks are reproducible from the script, and results are committed.
