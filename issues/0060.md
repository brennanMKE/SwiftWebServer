# 0060 — Add end-to-end HTTP/1.1 and HTTP/2 integration tests using curl

| | |
|---|---|

## Description

Automate real-client verification in `swift test`.

## Scope

- A test helper starts the server on an ephemeral port with a temporary document root (#0002) and runs `/usr/bin/curl` via `Process`.
- Cases: `--http1.1` GET, HEAD, and 304; `--http2-prior-knowledge` GET, HEAD, 304, 404, and 20 parallel fetches; `--http2 -k` over TLS; a large file whose checksum is compared.
- Tests assert the negotiated protocol from `curl -w '%{http_version}'`.

## Acceptance criteria

- All cases run in `swift test`, and the output shows each test executed.
