# 0049 — Dispatch each HTTP/2 stream to the handler in a child task and write responses as HEADERS and DATA frames

| | |
|---|---|
| **Status** | open |
| **Module** | HTTP2 |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

This is the milestone where browsers and curl can fetch files over HTTP/2.

## Scope

- When a request's header block completes, add a child task to the connection's task group that calls `HTTPHandler.handle`.
- Response HEADERS carry `:status` and lowercase fields with connection-specific fields removed. END_STREAM is set on HEADERS when the body is empty (HEAD, 304).
- The body is iterated and sent as DATA frames no larger than the peer's MAX_FRAME_SIZE, with END_STREAM on the last frame, or trailers as a final HEADERS frame.
- A handler error before HEADERS are sent becomes a 500. After HEADERS it becomes `RST_STREAM(INTERNAL_ERROR)`.

## Acceptance criteria

- `curl --http2-prior-knowledge http://localhost:8080/` returns the index page.
- `curl --http2-prior-knowledge --parallel -Z` fetches 20 URLs over one connection. Verify with `-v` that they are multiplexed.
