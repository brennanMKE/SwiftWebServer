# 0003 — SIGINT and SIGTERM are ignored, so the server cannot be stopped without SIGKILL

| | |
|---|---|
| **Status** | open |
| **Module** | Lifecycle |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

The running server ignores both Ctrl-C (SIGINT) and SIGTERM. The only way to stop it is `kill -9`. Verified on 2026-09-12: a server survived `kill -TERM` and two `kill -INT` signals.

## Steps to reproduce

1. `swift build && ROOT_PATH=$PWD/Root .build/debug/SwiftWebServer &`
2. `kill -INT <pid>`, then `kill -TERM <pid>`
3. `pgrep -fl SwiftWebServer`

## Expected behavior

The server logs shutdown, cancels the listener, and exits with status 0.

## Actual behavior

The process keeps running and keeps serving requests.

## Notes

`installSignalHandlers()` (`HTTPServer.swift:83-99`) sets `signal(sig, SIG_IGN)` and then creates each `DispatchSource` as a local constant that is never stored. The sources are most likely released when the function returns, which leaves the signals ignored with no handler. Store the sources for the life of the server. Add a test that sends SIGTERM to a child server process and asserts it exits.
