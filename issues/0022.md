# 0022 — 405 responses omit the required Allow header

| | |
|---|---|
| **Status** | open |
| **Module** | Semantics |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

Unsupported methods get `405 Method Not Allowed` (`HTTPServer.swift:183-186`) without an `Allow` header, which RFC 9110 §15.5.6 requires.

## Steps to reproduce

1. `curl -si -X POST http://localhost:8080/`

## Expected behavior

`405` with `Allow: GET, HEAD`.

## Actual behavior

`405` with no `Allow` header, plus an HTML body.

## Notes

`OPTIONS` should also return `Allow`, or be handled explicitly. Unknown methods may instead get `501 Not Implemented`.
