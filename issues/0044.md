# 0044 — Implement the HTTP/2 connection frame loop with a single-writer outbound queue

## Description

Build the `HTTP2Connection` runtime described in `HTTP2.md`. A reader loop iterates `http2Frames()` and feeds a pure `HTTP2ConnectionStateMachine` (wrapped in an actor). A single `FrameWriter` task drains an outbound queue.

## Scope

- `HTTP2ConnectionStateMachine` is a struct whose `mutating func receive(_:) throws(HTTP2Error) -> [Action]` does no I/O and never awaits.
- The `FrameWriter` is the only writer to the transport and the only owner of the HPACK encoder, so encoding happens in wire order and HEADERS + CONTINUATION frames are contiguous.
- The outbound queue is an AsyncSequence (for example, `AsyncStream` with explicit capacity accounting). Control-frame queue depth is tracked for #0056.
- The connection runs in `withThrowingDiscardingTaskGroup` with the writer and stream tasks as children. Reader end-of-input or error cancels the group.
- No Combine, and no unstructured `Task {}`.

## Acceptance criteria

- An in-memory transport test performs the preface and SETTINGS exchange and a clean close.
- A test proves that frames queued from many concurrent tasks never interleave inside a header block.
