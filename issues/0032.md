## Description

Response bodies are a single in-memory `Data`. Serve files as an `AsyncSequence` of fixed-size chunks read from a `FileHandle`, so memory use is independent of file size. HTTP/2 flow control (#0054) depends on writers pulling chunks as the window allows.

## Scope

- `HTTPBody.file(url:chunkSize:)` reads lazily in `next()` and closes the file when iteration ends or the task is cancelled.
- The HTTP/1.1 writer iterates the body and awaits each `Transport.write`.
- Validators come from metadata instead of hashing the full contents (#0025).

## Acceptance criteria

- Serving a 100 MB file keeps resident memory roughly flat (measure and note the result in the resolution).
- Cancelling mid-transfer closes the file handle.
