# 0016 — HEAD responses include the response body

| | |
|---|---|
| **Status** | open |
| **Module** | Semantics |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

HEAD requests receive the full body. `HTTPRequest.includeBody` (`HTTPRequest.swift:20`) exists but is never used, and `HTTPResponse.data` always appends the body. Verified on 2026-09-12: `curl -X HEAD http://localhost:8080/index.html` received 626 body bytes.

## Steps to reproduce

1. `curl -s -X HEAD http://localhost:8080/index.html --max-time 2 | wc -c`

## Expected behavior

0 bytes of body, and the same headers as GET, including `Content-Length: 626`.

## Actual behavior

626 bytes of body follow the headers.

## Notes

`docs/TODO.md` lists HEAD as implemented. Keep `Content-Length` equal to the GET body length while omitting the body.
