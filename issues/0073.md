# 0073 — ByteBuffer and ASCII and integer utilities provide allocation-free byte handling

| | |
|---|---|
| **Status** | open |

| **Platform** | macOS |

## Description

Every protocol layer parses and writes bytes directly (ROADMAP §7). Provide the one reusable byte container and the small ASCII helpers they all share, so no layer reaches for `Data`, `String` or Foundation on the hot path.

## Scope

- `ByteBuffer`: one growable buffer with separate reader and writer indices, `reserveCapacity`, `discardReadBytes` (compaction), `clear(keepingCapacity:)`, read/write of integers in network byte order, and borrowing views (`ByteView`) over ranges without copying. Unsafe pointers are confined to this type (ROADMAP §7 "Keep unsafe small"); use `Span`/`RawSpan` if #0069 found them available.
- `ByteView` / byte-range type used by `HTTPRequest` for path, query, authority and header values; `String` only on demand via an explicit conversion.
- ASCII utilities: 256-entry token and field-value tables, case-insensitive compare of lowercase literal against bytes, CR/LF scanning, decimal digit loops for `Content-Length` with overflow detection, hex parsing for chunk sizes, integer-to-ASCII into a buffer without `String`.
- FNV-1a hash of lowercased bytes computed in the same pass as a scan (used by #0074 for header name IDs).
- `BoundedAsyncQueue` and `Deadline` utilities from ROADMAP §5.4 if not owned elsewhere: a queue that suspends producers when full, with cancellation-safe waiters.

## Acceptance criteria

- `swift test --filter HTTPCoreTests` runs index, compaction, growth and integer round-trip tests, including overflow and reading past the writer index.
- `sws-bench bytes` reports 0 allocations per op for read/write/compaction after warm-up, and integer-to-ASCII under 20 ns.
- `BoundedAsyncQueue` tests show a producer suspends at capacity and resumes when a consumer reads, and that cancelling a suspended producer removes its waiter.
