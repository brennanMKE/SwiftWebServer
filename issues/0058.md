# 0058 — Negotiate h2 and http/1.1 with ALPN and route each connection to the matching codec

| | |
|---|---|
| **Status** | open |
| **Module** | TLS / Transport |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

Configure `NWProtocolTLS` with ALPN and choose the codec from the negotiated protocol.

## Scope

- `sec_protocol_options_add_tls_application_protocol` for `h2` then `http/1.1`. Minimum TLS 1.2, following the RFC 9113 §9.2 cipher suite requirements.
- The negotiated protocol is read with `sec_protocol_metadata_get_negotiated_protocol` and exposed as `Transport.negotiatedProtocol`.
- `h2` routes to `HTTP2Connection` (the preface is still required from the client). `http/1.1` or no ALPN routes to the HTTP/1.1 codec.
- HTTP/2 over TLS responses use `:scheme https`.

## Acceptance criteria

- `curl --http2 -k -v https://localhost:8443/` shows `ALPN: server accepted h2`.
- `curl --http1.1 -k https://localhost:8443/` works.
- An integration test covers both.
