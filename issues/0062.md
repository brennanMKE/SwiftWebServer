# 0062 — Verify browser interoperability over TLS

| | |
|---|---|
| **Status** | open |
| **Module** | Conformance / TLS |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

Confirm that Safari, Chrome, and Firefox load the sample site over HTTP/2 with the dev certificate trusted.

## Scope

- Load `https://localhost:8443/` and the tab pages, and confirm the protocol column shows `h2` in each browser's network inspector.
- Test hard reloads (conditional requests, 304 over HTTP/2), image loads, and navigation while a large file downloads.
- Record findings in the resolution, and file separate issues for any bugs.

## Acceptance criteria

- All three browsers load every page over h2 without console errors.
