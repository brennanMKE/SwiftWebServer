# 0037 — Implement HPACK integer and string literal primitives

| | |
|---|---|
| **Status** | open |
| **Module** | HPACK |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

Create the `HPACK` target (pure Swift, no Foundation) with the primitive representations from RFC 7541 §5.

## Scope

- N-bit prefix integer encode and decode (§5.1) with overflow protection, rejecting values above a sane limit.
- String literal encode and decode (§5.2) with the H bit selecting Huffman or raw. Huffman is provided by #0038.

## Acceptance criteria

- RFC 7541 Appendix C.1 integer examples (10 with a 5-bit prefix, 1337 with a 5-bit prefix, 42 at an octet boundary).
- A malformed or oversized integer throws.
