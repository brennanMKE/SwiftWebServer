# 0092 — VirtualHosts component routes requests by Host to separate component chains

| | |
|---|---|
| **Status** | open |
| **Module** | VirtualHosts |
| **Platform** | macOS |
| **First seen** | 2026-11-11 |

## Description

One server should serve several sites selected by `Host`/`:authority`.

## Scope

- Host matching on the authority bytes (exact and `*.suffix` wildcard), port stripped, case-insensitive, no `String` on the hot path.
- Each host has its own chain (e.g. its own StaticFiles root); a default host or `421 Misdirected Request` when none matches.
- Host name stored in `RequestContext` for logging.

## Acceptance criteria

- `curl -H 'Host: a.test' ` and `curl -H 'Host: b.test'` against one port return different roots; an unknown host returns the default or 421 per configuration.
- `sws-bench` shows no change (< 2%) with the component unregistered.
