# 0024 — maxConnections, enableCompression, and enableETags are parsed but never used

| | |
|---|---|
| **Status** | open |
| **Module** | Config |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

These `HTTPConfig` fields have no effect:

- `maxConnections`: accepted connections are unbounded.
- `enableCompression`: no `Content-Encoding` is ever applied.
- `enableETags`: ETags are always computed and sent.

(`keepAliveTimeout` and `maxRequestSize` are covered by #0012 and #0011.)

## Expected behavior

Each option either works as documented or is removed from the config and docs.

## Actual behavior

The options are silently ignored.

## Notes

#0029 is the natural place to enforce `maxConnections`. Compression, if kept, should negotiate via `Accept-Encoding` and add `Vary: Accept-Encoding`.
