# 0010 — Connection state handler is installed after the connection starts

| | |
|---|---|
| **Status** | open |
| **Module** | Connection |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

`connection.start(queue:)` is called at `HTTPServer.swift:105`, and `stateUpdateHandler` is only assigned afterward at `HTTPServer.swift:109`. State transitions that happen in between (`.preparing`, `.ready`, or an immediate `.failed`) can be missed, so a failed connection may never be logged or cleaned up.

## Expected behavior

Handlers are installed before `start(queue:)`.

## Actual behavior

There is a window where state changes are unobserved.

## Notes

This is low severity on its own, but the transport adapter in #0028 should get the ordering right.
