# 0056 — Mitigate known HTTP/2 denial-of-service patterns

| | |
|---|---|
| **Status** | open |
| **Module** | HTTP2 |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

Defend against the published HTTP/2 attack classes with counters in the connection state machine. Violations trigger `GOAWAY(ENHANCE_YOUR_CALM)`.

## Scope

- **Rapid reset (CVE-2023-44487):** limit client-initiated resets per time window.
- **CONTINUATION flood (VU#421644):** cap accumulated header block bytes and CONTINUATION count per block.
- **Control-frame floods:** cap queued outbound PING ACKs and SETTINGS ACKs (the writer's control queue depth).
- **Empty frame flood:** limit zero-length DATA frames without END_STREAM, and empty CONTINUATIONs.
- **HPACK bomb:** incremental header list limit (#0040) and a dynamic table bounded by the advertised size.
- **Zero-window stall:** close streams or connections whose send window stays at 0 beyond a timeout.
- **Slow preface:** close if the preface and SETTINGS do not arrive within a timeout.
- Every threshold is configurable, and the defaults come from the limits table and DoS list in `docs/HTTP2.md`.

## Acceptance criteria

- One in-memory transport test per attack asserts GOAWAY and bounded memory.
