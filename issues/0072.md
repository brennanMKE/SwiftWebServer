## Description

Earlier exit criteria depended on tools nobody had installed (ROADMAP §4). Make every external tool and certificate a later milestone needs an explicit, scripted prerequisite, and document how to verify each one.

## Scope

- Document and check `brew install h2spec nghttp2 oha curl` in `scripts/check-tools.sh`, which prints each tool's version and fails if one is missing. Homebrew curl must report `HTTP3` in `/opt/homebrew/opt/curl/bin/curl --version` Features; the system `/usr/bin/curl` (8.7.1, no HTTP/3) is not enough for Track A.
- `scripts/make-test-identity.sh` creates a local CA and a `localhost` / `127.0.0.1` / `::1` server certificate with `openssl`, exports a PKCS#12 identity with a known test password into a git-ignored `TestIdentity/` folder, and is idempotent.
- Instructions (not automation) for optionally trusting the local CA in the login keychain for browser tests (#0105, #0062); tests must not require that trust and use `-k` or a `URLSession` trust override instead.
- `HTTPTestSupport` gains a helper that locates the identity and skips TLS tests with a clear message when it is absent.
- Docker is not installed; Autobahn runs stay optional (#0109).

## Acceptance criteria

- `scripts/check-tools.sh` exits 0 on this machine and prints versions for h2spec, h2load, nghttp, oha and Homebrew curl with HTTP3.
- `scripts/make-test-identity.sh` run twice produces a usable identity; `openssl pkcs12 -info -in TestIdentity/server.p12 -passin pass:<test password> -nokeys` shows the `localhost` certificate with the expected SANs.
- `openssl s_server` started with the generated certificate answers `curl --cacert TestIdentity/ca.pem https://localhost:<port>/` without `-k`.

## Notes

- **Test identity (done, with #0098):** `scripts/make-test-identity.sh` (adapted from `Spikes/QUICSpike/make-identity.sh`) writes a self-signed `localhost` / `127.0.0.1` / `::1` certificate, its key, `cert.der`, and `server.p12` (password `sws-test-password`, legacy PBE-SHA1-3DES so `SecPKCS12Import` accepts it) into the gitignored `.test-identity/` folder (not `TestIdentity/` as the scope says). It is idempotent (`--force` regenerates) and atomic (built in a temp folder, `server.p12` moved last), so parallel test processes are safe. It prefers Homebrew OpenSSL over the system LibreSSL.
- `HTTPTestSupport.TestIdentity.load()` returns the bytes and runs the script when the files are missing; `NetworkTransport.TLSIdentity(pkcs12:password:)` imports them with `kSecImportToMemoryOnly: true` only. #0087 should reuse both.
- **Still open: the local CA** (CA-signed server certificate, `curl --cacert` check) and `scripts/check-tools.sh`.
- **Trusting a local CA for browser checks (#0105, #0062) is a manual step for the owner.** It changes the login keychain's trust settings and raises a macOS authorization prompt, so agents must never run it (AGENTS.md: no `security add-trusted-cert`, no `SecTrustSettingsSetTrustSettings`, no keychain writes). Document the command for the owner; tests never depend on it (they pin the certificate or use `curl -k`).
