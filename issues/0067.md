# 0067 — Support extended CONNECT for WebSockets over HTTP/2

| | |
|---|---|
| **Status** | open |
| **Module** | HTTP2Connection / Optional |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

Implement RFC 8441 so WebSockets (planned in `TODO.md`) work over HTTP/2 streams as well as HTTP/1.1 Upgrade.

## Scope

- Advertise `SETTINGS_ENABLE_CONNECT_PROTOCOL = 1`.
- Accept `:method CONNECT` with `:protocol websocket`, `:scheme`, `:path`, and `:authority`, and respond with a 200 HEADERS frame that keeps the stream open.
- Expose the stream as a bidirectional byte AsyncSequence to the WebSocket layer, which is shared with the HTTP/1.1 Upgrade path.

## Acceptance criteria

- The Autobahn test suite scripts in the repo (`run-autobahn-*.sh`) pass over the HTTP/1.1 path, and a browser WebSocket connects over h2.
