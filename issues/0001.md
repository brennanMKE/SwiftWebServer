# 0001 — Project has no test target, so fixes cannot be verified

| | |
|---|---|
| **Status** | open |
| **Module** | Tests |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

There is no `Tests/` directory and no test target in `Package.swift`, so `swift test` has nothing to run. Every other issue's resolve workflow requires tests that actually execute, so this blocks all of them.

## Expected behavior

`swift test` builds and runs a `SwiftWebServerCoreTests` target that uses the Swift Testing framework (`import Testing`), with at least one passing test that exercises real code (for example, `HTTPRequest.parse` on a simple GET).

## Actual behavior

`swift test` reports no tests. `scripts/commands.txt` references a `SwiftWebServerFunctionalTests` target that does not exist.

## Notes

- Add `.testTarget(name: "SwiftWebServerCoreTests", dependencies: ["SwiftWebServerCore"])` to `Package.swift`.
- Use Swift Testing (`@Test`, `#expect`), not XCTest.
- Update the "Build / verify command" section in `issues/Issues.md` if the command differs from `swift test`.
