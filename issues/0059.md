# 0059 — Serve cleartext and TLS listeners concurrently

| | |
|---|---|
| **Status** | open |
| **Module** | TLS / Lifecycle |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

Run the HTTP and HTTPS listeners at the same time under one structured shutdown.

## Scope

- `Server.run()` starts both listeners as children of one task group. Shutdown cancels both and drains connections (#0052).
- An optional `redirectToHTTPS` sends `308` from cleartext HTTP/1.1 to the TLS port.
- Logs show both bound ports.

## Acceptance criteria

- An integration test fetches from both ports and then shuts down cleanly.
