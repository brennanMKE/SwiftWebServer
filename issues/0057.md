## Description

Load a server identity for HTTPS. Browsers only speak HTTP/2 over TLS.

## Scope

- A `tls` config section (`enabled`, `port`, `identity` path to a PKCS#12 file, and the name of the passphrase environment variable), with defaults per #0023.
- Load a `SecIdentity` via `SecPKCS12Import`, and fail fast with a clear error when the file is missing, the passphrase is wrong, or the certificate is expired.
- A `make-dev-cert.sh` script that uses `openssl` (installed at `/opt/homebrew/bin/openssl`) to create a localhost CA and server certificate as a `.p12`, plus instructions for trusting it in the macOS keychain. The certificate directory is git-ignored.

## Acceptance criteria

- A unit test loads a test `.p12` generated in the test's temporary directory.
- The error cases are covered by tests.
