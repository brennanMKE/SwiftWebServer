# 0009 — Errors thrown while building a response leave the connection open with no reply

| | |
|---|---|
| **Status** | open |
| **Module** | Connection |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

`try await self.respond(to: request)` (`HTTPServer.swift:164`) runs inside an unstructured `Task`. If `respond` throws (for example, `runtime.config` throws `notBootstrapped` or a stored failure), the error ends the task silently. No response is sent and `connection.cancel()` is never called, so the socket leaks until the client gives up.

## Expected behavior

A thrown error is logged, a 500 is sent, and the connection is closed.

## Actual behavior

The error is silently dropped and the connection is left open.

## Notes

#0029 moves connection handling into a task group, where child errors must also be handled explicitly.
