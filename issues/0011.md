# 0011 — Request buffer grows without limit because maxRequestSize is ignored

| | |
|---|---|
| **Status** | open |
| **Module** | Security / Connection |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

Incoming bytes are appended to `buffer` (`HTTPServer.swift:138`) with no upper bound. `HTTPConfig.maxRequestSize` (10 MiB in `Root/http-config.json`) is decoded but never read. Once #0006 makes the server wait for the full header section, a client can send endless header bytes and exhaust memory.

## Expected behavior

Header sections larger than a configured limit get `431 Request Header Fields Too Large` and bodies larger than `maxRequestSize` get `413 Content Too Large`, and the connection closes.

## Actual behavior

There is no limit.

## Notes

`ConnectionStream` also buffers into an unbounded `AsyncStream` (`HTTPServer.swift:327`). See #0028.
