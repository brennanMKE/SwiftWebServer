# 0100 — HTTP/3 control streams exchange SETTINGS and classify unidirectional streams

| | |
|---|---|
| **Status** | open |
| **Module** | HTTP3 |
| **Platform** | macOS |
| **First seen** | 2026-11-11 |

## Description

An HTTP/3 connection opens its control stream and QPACK encoder/decoder streams and validates the peer's (RFC 9114 §6.2, §7.2.4).

## Scope

- `H3Connection` state machine: on start, open control (type 0x00) with SETTINGS first, QPACK encoder (0x02) and decoder (0x03) streams.
- `UniStreamClassifier`: read the stream type varint; control, push (reject: we are a server), QPACK encoder/decoder, reserved/unknown types ignored with STOP_SENDING `H3_STREAM_CREATION_ERROR`.
- SETTINGS: `QPACK_MAX_TABLE_CAPACITY = 0`, `QPACK_BLOCKED_STREAMS = 0`, `MAX_FIELD_SECTION_SIZE` from limits, `ENABLE_CONNECT_PROTOCOL` when WebSockets are registered (#0111); duplicate control stream, missing SETTINGS first, duplicate setting identifiers, and HTTP/2 setting IDs are connection errors.
- Closing a critical stream is `H3_CLOSED_CRITICAL_STREAM`.

## Acceptance criteria

- In-memory tests (#0099) for each rule above, asserting the exact error code.
- `/opt/homebrew/opt/curl/bin/curl --http3-only -k -v` shows the connection established and SETTINGS exchanged (request handling may still 404 until #0101).
