## Description

Implement GOAWAY (RFC 9113 §6.8) for both error handling and orderly shutdown.

## Scope

- A connection error sends `GOAWAY(lastProcessedStreamID, code, debugData)`, flushes the writer, closes the transport, and cancels the group.
- Graceful shutdown (triggered by `ServerLifecycle` entering draining (#0079) or the idle timeout) sends `GOAWAY(2³¹−1, NO_ERROR)`, waits for a PING round-trip, then sends the final `GOAWAY(lastStreamID)`. In-flight streams drain up to a deadline, and new streams above the last id are refused.
- A GOAWAY received from the peer stops new streams, lets existing streams finish, and then closes.

## Acceptance criteria

- A test starts a slow download, triggers server shutdown, and asserts that the download completes, a new stream is refused, and `run()` returns.
