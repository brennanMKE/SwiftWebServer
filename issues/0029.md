# 0029 — Accept connections with a discarding task group instead of unstructured Tasks

| | |
|---|---|
| **Status** | open |
| **Module** | Connection / Lifecycle |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

The listener yields connections into an unbounded `AsyncStream`, and each connection is handled in a detached `Task {}` (`HTTPServer.swift:101-176`), so shutdown cannot cancel in-flight work and nothing bounds concurrency. Make the listener an `AsyncSequence` of transports and serve them from `withThrowingDiscardingTaskGroup`.

## Scope

- `listener.connections` is an AsyncSequence of `Transport`.
- `Server.run()` runs one child task per connection. Once `maxConnections` connections are active, new ones are closed immediately or accepts wait (#0024).
- Shutdown via `ExitHandler` cancels the group. Every connection closes and `run()` returns.
- Child task errors are logged and never tear down the group.

## Acceptance criteria

- A test starts a server, opens N connections, triggers shutdown, and asserts that all connections close and `run()` returns.
