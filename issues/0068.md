# 0068 — Accept HTTP/1.1 Upgrade to h2c

| | |
|---|---|
| **Status** | open |
| **Module** | HTTP1 / Optional |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

Support `Upgrade: h2c` with `HTTP2-Settings` from RFC 7540 §3.2. RFC 9113 deprecates this mechanism, so implement it only for older clients, behind a config flag.

## Scope

- Validate `Connection: Upgrade, HTTP2-Settings` and decode the base64url `HTTP2-Settings` header.
- Respond `101 Switching Protocols`, then send the server preface. The original request becomes stream 1 (half-closed remote), and the HTTP/1.1 request body must be fully read first.

## Acceptance criteria

- `curl --http2 http://localhost:8080/` (which attempts the upgrade over cleartext) negotiates HTTP/2 when the flag is enabled.

## Relation

- **Phase:** 12 — Optional HTTP/2 extensions
- **Blocked by:** #0033, #0049
