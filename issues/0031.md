# 0031 — Define the HTTPHandler protocol and move static file serving into a handler

| | |
|---|---|
| **Status** | open |
| **Module** | Semantics / StaticFiles |
| **Platform** | macOS |
| **First seen** | 2026-09-12 |

## Description

Request handling is hard-wired into `HTTPServer.respond(to:)`. Define `protocol HTTPHandler: Sendable { func handle(_ request: HTTPRequest) async throws -> HTTPResponse }` and move file serving into `StaticFileHandler`, so HTTP/1.1 and HTTP/2 call the same code. This also establishes the middleware interface planned in `docs/MIDDLEWARE.md`.

## Scope

- `StaticFileHandler` keeps all of today's behavior: block list, containment, index files, MIME types, conditional requests, and caching headers.
- A middleware composition: `protocol HTTPMiddleware { func handle(_ request: HTTPRequest, next: some HTTPHandler) async throws -> HTTPResponse }`.
- Codecs map thrown errors to 500.

## Acceptance criteria

- `StaticFileHandler` is tested directly with no sockets.
- The server is wired through the handler.
