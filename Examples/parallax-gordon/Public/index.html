SwiftWebServer on gordon

A dependency-free Swift HTTP server serving this page from disk and reverse-proxying two System 1 decision models on this Mac mini's loopback. It is the only process on the tailnet: it checks the bearer key, forwards, health-checks the backends and logs every request.
